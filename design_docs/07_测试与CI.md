## 3. CI workflow（GitHub Actions：windows-latest + linux(v0.1.2-linux 起) + deny）

```mermaid
flowchart LR
    PUSH[push/PR] --> JOB[windows-latest]
    PUSH --> LINUX[ubuntu-latest<br/>apt install keepassxc]
    JOB & LINUX --> CACHE["缓存: Swatinem/rust-cache\n(cargo registry/target)\n+ choco/apt 缓存 keepassxc"]
    CACHE --> INST["安装: rustup toolchain(rust-toolchain.toml)"]
    INST --> LINT["cargo fmt --check / clippy -D warnings"]
    LINT --> TEST["cargo test\n(集成测试定位 keepassxc-cli:\nSP_KEEPASSXC_CLI 覆盖 → 平台默认路径)"]
    TEST --> SEC["cargo deny / audit\n(独立 deny job, 容器 action 仅 Linux)"]
    SEC --> BUILD["cargo build --release\n+crt-static (仅 windows tag)"]
    BUILD --> PKG["打包 sp.exe+README+SHA256SUMS\n上传 artifact (仅 windows tag)"]
```

要点：rust-toolchain.toml 锁 1.99.1；性能测试 `#[ignore]` 不阻塞 CI（SP-N-301）；`SP_SKIP_INTEROP=1` 后备仅在 keepassxc 安装失败时允许且日志必须可见（防假绿）；**cargo-fuzz 不进 CI**——fuzz/ 为独立 workspace，仅本地短跑（结果入 docs/reviews/）。

## 4. KAT/向量来源（SP-C-106）

XChaCha20-Poly1305：draft-irtf-cfrg-xchacha 官方向量；AEAD 基础：RFC 8439；Argon2id：参考实现向量；plus keepass_ng 自带测试。**禁止自造密文向量**；round-trip 数据由程序生成。

## 5. 覆盖率目标

加密/密钥路径（sp-core）100%；解析器与去重 ≥90% 行覆盖（tarpaulin/cargo-llvm-cov 本地度量，CI 记录不强阻塞）；遮蔽过滤器 100%（含跨边界用例）。
