# 15 桌面形态：Tauri 托盘 + 会话双超时 + NM host 单进程嵌入（SP-F-9xx）

- 状态：v1.0（2026-10-29，DR-013 批次 1 实现，任务书_step7）
- 上游依赖：design_docs/11（NM 协议，协议层原样复用）、design_docs/13 §2（actor 线程模型）、DR-013（凭据驻留策略桌面口径）、DR-006（方案 A 进程内会话）
- 范围：Windows 桌面批次 1（`desktop/` 独立 workspace）；macOS、Android 生物识别（批次 2）、P2 协议加密、密钥复用开库不在本期

## 1. 目标与验收锚点

- SP-F-901 托盘常驻壳：主窗隐藏/托盘常驻/关窗=隐藏；托盘菜单=显示解锁窗/立即锁定/设置/退出
- SP-F-902 解锁会话：**每次进程启动首次主密码**（DR-013）；解锁 → 因子留驻 sp-kffi actor（DR-012 A1 同源）；锁库随 actor drop 清零；无生物、无落盘（不触碰红线 #5 豁免——那是 Android 生物路径专属）
- SP-F-903 双超时：idle（touch 刷新）与 absolute（自解锁时刻）独立可配，默认 300s/1800s；任一到即锁库，再次使用须重新主密码
- SP-F-904 设置持久化：%APPDATA%/SuperPasswdKey/settings.json（仅非机密 idle_ms/absolute_ms/autostart）；损坏/缺失回落默认值不崩；超时配置重启生效
- SP-F-905 开机自启：HKCU\…\Run 用户级注册表值（免管理员，手写 registry）；settings.json 为偏好单一来源，启动与保存时对账
- SP-F-906 NM host 单进程嵌入：注册表 manifest 指向 sp-desktop.exe；协议编解码/动作分发/请求循环复用 sp-nmhost 库目标（零复制）；锁定态机密请求 → 回 locked 语义 + 弹解锁窗；端口关闭 → 进程退出
- SP-F-907 浏览器填充链路（桌面）：sp.get-logins URL 匹配 + sp.get-secret 单条显式取回，动作纪律与 SP-F-702/706 单源

验收：托盘 GUI 解锁/锁定/双超时/自启/设置持久化；扩展经 sp-desktop 填充链路（模拟 NM 握手测试 + 手工 Chrome 验证）；CI desktop job 全绿。

## 2. 进程模型（结构性决策）

```
┌─ 托盘实例（用户/自启拉起，无 NM 参数）─┐   ┌─ NM 实例（浏览器 connectNative 拉起）─┐
│ 托盘 + 解锁/设置窗 + Session          │   │ 解锁/设置窗（初始隐藏）+ Session      │
│ 启动即弹解锁窗（首次主密码）          │   │ NM 循环线程 + 双超时 watcher 线程     │
└──────────────────────────────────┘   │ locked 请求 → 弹解锁窗；EOF → 退出    │
                                        └───────────────────────────────────┘
        两实例互不感知、各自闭环（DR-013："每次进程启动首次主密码"）
```

- **单进程架构**（任务书设计闸门）：sp-desktop.exe 同时是托盘 GUI 进程与 native messaging host。浏览器经 manifest 拉起的实例在专用线程跑 NM 循环，与会话管理器共享进程内同一 `Session`——会话进程内闭环，免跨进程会话共享/IPC，收敛 DR-006 遗留"跨进程持久化缓存 backlog"。
- **多实例语义**：托盘实例与 NM 实例并存属预期（各持有独立会话）。这直接落实 DR-013"每次进程启动首次主密码"：浏览器拉起的 NM 实例初始锁定，扩展首请求到达 → 回 `locked` → 弹出本实例解锁窗，主密码在窗口输入（不经 NM 管道）；解锁后填充链路在本实例会话内完成。浏览器断开（stdin EOF）该实例即退出，会话随进程清零。
- **NM 模式判定**：argv[1] 为 `chrome-extension://` 前缀（`sp_nmhost::origin::launched_by_browser`）。托盘实例启动即弹窗；NM 实例初始隐藏（tauri.conf.json `visible:false`，setup 按模式显隐）。

## 3. 组件结构（desktop/src-tauri）

| 组件 | 职责 |
|---|---|
| `main.rs` | 装配：读设置 → 自启对账 → 会话构造 → 托盘/窗口 → NM 模式判定与派发。Tauri command：session_status/unlock/lock_now/touch/get_settings/save_settings；机密纪律：password 仅存在于 command 调用栈 |
| `session.rs` | 会话状态机（批次 1 已落地）：复用 sp-kffi 线程封闭 actor（keepass_ng Database !Send+!Sync）；idle/absolute 惰性双检查；`lock_now`=drop Vault（凭据随 actor 清零）；单库路径 %APPDATA%/SuperPasswdKey/vault.kdbx |
| `settings.rs` | settings.json 读写（serde_json；BOM 兼容）；损坏/缺失回落默认值；仅非机密字段（idle_ms/absolute_ms/autostart）——任何凭据不入此文件 |
| `autostart.rs` | HKCU Run 写/删/查（winreg，手写 registry 免管理员）；值名 `SuperPasswdKey`，值=带引号 exe 全路径；`reconcile` 按偏好对账（用户手删注册表值后重启即恢复，关偏好即清残留） |
| `nm.rs` | NM 嵌入：`DesktopNmSession` 适配器（实现 sp-nmhost `NmActionSession`，桥接 Vault actor 会话）；serve 循环线程（stdin/stdout）；双超时 watcher（解锁态翻转即发 `sp.event locked`）；locked 错误同步弹解锁窗；EOF → `app.exit(0)` |
| `desktop/ui/`（静态零 Node） | 解锁/状态窗 + 设置区（空闲/绝对分钟数 + 自启开关）；密码经 Tauri invoke 直达 Rust，JS 不落存储/日志（对齐 SP-F-804 审查口径） |

## 4. sp-nmhost 库化增量（不改既有公开行为）

- `actions.rs`：动作分发 trait 化（`NmActionSession` + `EntryDigest`）。分发纪律单源：无全库导出动作、锁定态机密操作 → `locked`、成功请求统一 touch、机密值不进错误链。原因子缓存 `Session` 实现该 trait，既有 30 测试语义不变。
- `nm_loop.rs`（新）：`serve(input, &Mutex<out>, dispatch)` 请求循环——每帧 读入→分发→响应信封整形（action/requestID/success/data|error）。输出互斥锁按帧持有，watcher 的 `sp.event` 与响应帧不交错。bin 与桌面嵌入共用；`ServeEnd::{Eof, Protocol}` 区分端口关闭与协议错误。
- `origin.rs`（新，自 bin 下沉）：`bound_origin`（--allowed-origin > SP_NM_ALLOWED_ORIGIN > nm-host-config.json，desktop 无 CLI 口取后两级）、`caller_origin`、`check_caller_origin`（manifest allowed_origins 之外的 host 侧第二道防线）、`launched_by_browser`。桌面嵌入与 bin 同一道防线。
- bin `main.rs`：薄壳化（参数解析+装配），循环/origin/分发全部走库目标；旧 sp-nmhost 回归 = 既有注册与测试不变（迁移期双轨）。

## 5. 交互流（DR-013 桌面口径逐条映射）

1. 开机自启（SP-F-905）→ 托盘实例启动 → **弹解锁窗**（首次主密码，SP-F-902）。
2. 浏览器扩展 connectNative → NM 实例拉起（初始隐藏、会话锁定）→ `sp.get-logins` 到达 → 回 `locked` → **弹本实例解锁窗**（SP-F-906）；用户输入主密码 → 解锁成功 → 扩展重试 → 匹配/取密（SP-F-907）。
3. 空闲/绝对超时到期（SP-F-903）→ watcher 主动锁库 + `sp.event locked` 通知扩展（惰性检查兜底：机密操作永不越过过期态）；再次使用须重新主密码。托盘/NM 双实例独立计时。
4. 设置窗（SP-F-904）：改超时（重启生效）+ 自启开关（即时写注册表）；关窗=隐藏，托盘"设置"可再唤出。

## 6. 机密纪律与威胁模型

- 主密码/因子只在 Rust 侧：Tauri command 边界即用即弃（unlock 传给 sp_kffi::open_db 后随栈帧释放）；NM 侧主密码仅经 `sp.unlock` 请求帧进入 actor（与 sp-nmhost bin 同面）。因子随 open_db 留驻 actor（DR-012 A1，桌面与 Android 同威胁模型，DR-013 已声明内存驻留窗口=会话期）。
- 前端 JS 不接触明文凭据：输入瞬态即传 invoke；不写 localStorage/日志。
- settings.json 仅非机密；nm-host-config.json 仅 origin/keyfile 路径（keyfile 是文件路径非机密值）。
- 红线 #5 定向豁免（Keystore 包裹落盘）为 Android 生物路径专属，桌面批次不触碰。

## 7. 供应链（deny 差异披露）

desktop 独立 workspace 引入 Tauri 依赖树（≈487 包），`desktop/src-tauri/deny.toml` 与根配置差异：
- `bans.deny` 清空：Tauri 运行时自带 tokio（async runtime），GUI 壳无法避开；**sp-\* 内核 crate 的零网络 crate 禁入（SP-N-304）仍由根 workspace deny 把守**，不受影响。桌面壳运行期零网络由补偿控制约束：CSP `default-src 'self'`、不接 updater/远程内容、前端零 Node 依赖。
- `graph.targets` 收敛 x86_64-pc-windows-msvc（desktop 批次即 Windows 主线）：linux gtk 链不进扫描面（顺带排除 linux 专属 RUSTSEC-2024-0370 proc-macro-error）。
- 豁免：RUSTSEC-2026-0374 basic-toml（uniffi_bindgen/askama 构建期宏传递依赖，与根配置对同一公告的豁免同源，随 uniffi 升级重审）。
- reqwest/hyper 出现于历史 Cargo.lock 残留（不在 sp-desktop Windows 构建图，`cargo tree -i` 验证为空），后续 solve 自动清除。

## 8. 注册与分发

- `native-host/register.ps1 -Target desktop`：manifest 指向 sp-desktop.exe（同一 host 名 `com.superpasswdkey.host`，重跑脚本即切换，迁移期与 sp-nmhost 双轨）；desktop 模式不写 db_path/session_timeout_secs（归桌面单库与设置窗），keyfile 经 `-KeyfilePath` 写入 nm-host-config.json。
- CI desktop job（windows-only）：fmt/clippy/test + `cargo tauri build`（NSIS）；deny job 增 desktop manifest 扫描。六既有 job 不回退。

## 9. 测试与已知边界

- 单测：会话（解锁/错密码/超时/重解锁，批次 1）、settings（roundtrip/损坏回落/BOM）、autostart（独立值名真实注册表 roundtrip）、nm（模拟 NM 握手全链路：ping→错密码→解锁→get-logins（无密码泄漏）→get-secret→lock→locked；status 回显库路径与空闲超时）。
- 手工验收项（用户侧）：Chrome 加载扩展 + `-Target desktop` 注册 → 填充全链路；双超时到期重新验证；自启注册表 `reg query` 验证。
- 已知边界：托盘实例与 NM 实例会话独立（每进程一次主密码，DR-013 口径）；库需 keyfile 时 NM 侧须 `-KeyfilePath` 预配置，否则解锁报 credentials；NM 实例在浏览器连接期常驻（含一个托盘图标），断开即退。
