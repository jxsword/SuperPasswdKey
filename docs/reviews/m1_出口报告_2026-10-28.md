## 3. 实测记录（模拟器 Pixel_7_API34，x86_64，非真机口径）

### 3.1 e2e 断言集（TestActivity，最终代码状态复跑）
- openDb（64MiB/t=8/p=4）：2306 ms，VmHWM delta 68408 kB
- findEntry 全字段读回 / 摘要面不含密码 / TOTP 6 位码 / NotFound / 错密码 Credentials / 复测 1823–2426 ms：全 PASS
- **首建校准链路**（init_vault=true，走 VaultSession.createVault）：3616 ms，校准结果 **m=65536 KiB / t=2 / p=4**（快机 t 触底，符合 DR-010 边界 [2,8]）
- **超时锁库注入**（idle_timeout_ms=2000）：超时后会话锁定、activeVault()==null（机密操作拒绝）——PASS

### 3.2 UI 回归（adb input/uiautomator 驱动）
- **手动解锁**：MainActivity 状态面板（库文件/会话/空闲锁库）→ UnlockActivity 解锁模式 → 解锁成功（logcat `session unlocked (vault.kdbx)`）
- **首次初始化**：删除 vault.kdbx → 创建模式（双密码框）→ 双密码不一致被客户端校验拦截（"主密码为空或两次输入不一致"）→ 输入一致后创建 → logcat `vault created (calibrated m=65536 t=2 p=4)` → 界面回显"已创建并解锁（校准参数 m=64MiB t=2 p=4）"
- **错误呈现**：错密码 → "解锁失败：主密码或 keyfile 不正确"（FfiException.Credentials 分类提示；日志仅记类别）
- **认证回路全链路**（本次回归修复后）：锁定态聚焦演示登录页字段 → 认证数据集（"SuperPasswdKey 点击解锁库后填充"）→ UnlockActivity（auth-loop 模式）解锁 → `auth loop: response built (1 datasets)` 回传系统 → 点选数据集 → 字段填充（username len=9 / password len=13，日志只记长度——SP-F-804 纪律）

### 3.3 回归发现与修复（本任务产出）
- **认证 Dataset presentation 缺失**：三参 `setAuthentication(ids, intentSender, null)` 在 API 33+ 抛 `IllegalArgumentException: authentication and presentation must be both non-null or null`，锁定态认证数据集无法下发。步骤 4 只验证过已解锁直填路径，未触达该分支——本次"认证回路回归"任务项的直接捕获。修复：presentation 复用 dataset_item 样式（commit `fix(android)`）。
- **UI 自动化坑位**（后续复用）：API 34 模拟器 shell 无 START_ANY_ACTIVITY，非导出组件不能 `am start`（故 TestActivity 保留导出）；UnlockActivity 自身密码框也会触发本应用 Autofill 弹窗（锁定态=认证数据集）抢走 `input text` 按键——UI 驱动测试时需先 `settings put secure autofill_service null` 或先解锁会话；软键盘弹出引起布局平移，固定坐标点击需先收键盘。

## 5. 机密边界审查（SP-F-804）

- **SharedPreferences/持久层**：全壳层零使用（grep 证据）；唯一文件写 = TestActivity result.txt（断言行，无凭据值）；库文件经 FFI 写入（KDBX4 加密）。
- **日志**：凭据值零出现——错误仅记 `FfiException` 类别；填充观测仅记字段名+长度；KDF 参数（m/t/p）非机密可记；SpAutofillService 节点调试日志（Log.d）仅 className/webDomain/hints/inputType。
- **内存边界**：凭据只进 FFI 调用栈（UnlockActivity 后台线程闭包 → VaultSession.unlock/createVault → openDb）；会话凭据随 actor drop 零化（Vault.lock）；JNI String 不可零化限制（R13-1）如实维持。
- **Manifest**：allowBackup=false（步骤 4 已有）；exported 最小化：MainActivity（launcher）+ TestActivity（adb 直驱 harness，注释说明）导出，DemoLogin/DemoWeb/Unlock 均非导出（系统经 PendingIntent 唤起 UnlockActivity 不受影响）。
- **已知姿势（如实声明）**：`usesCleartextTraffic="true"` 为演示链路（127.0.0.1 演示站）保留，产品化时收敛为 networkSecurityConfig 白名单；R13-1（JVM 堆密码副本）维持用户文档边界声明。
