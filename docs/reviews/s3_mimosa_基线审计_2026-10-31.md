## 5. 重点新增面复审明细（核实为安全的部分）

- **sp-kffi Rust-only 面**：`find_entry_full/delete_entry/list_attachments` 无
  `#[uniffi::export]`→Kotlin 绑定零漂移；解锁门在 `open_db` 构造（凭据校验失败
  即无 Vault 句柄），三函数与其余命令走同一 actor 通道，无绕过路径
  （`crates/sp-kffi/src/lib.rs:595-623`）。
- **sp run 注入路径**：程序名来自用户显式 `sp run -- <cmd>`，argv 直 exec 无
  shell（`crates/sp-cli/src/spawner.rs`）；`sp://` 格式校验前置于解锁；受保护
  变量拒绝注入；遮蔽器跨 chunk 有 proptest（`crates/sp-cli/src/f8.rs`）。工具
  链 1.99.1 ≥ 1.77.2，BatBadBut（CVE-2024-24576）已由 std 缓解。
- **桌面会话**：全部 Tauri command 经 `active_vault()` 惰性双超时检查，过期即
  锁库；写操作另需 `session_db_path()`（锁定即 None）——锁定拒绝全覆盖且有测
  试锚定（`desktop/src-tauri/src/session.rs`）。错误映射 `describe()` 不携带凭据值。
- **GUI 前端**：无 v-html/innerHTML/eval/localStorage/sessionStorage/document.cookie
  （全量 grep 核实）；密码仅经 invoke 参数瞬态传递；编辑防锁 onMounted/onUnmounted
  对称复位；剪贴板走 Rust arboard 30s 清空。
- **Tauri 配置**：CSP `default-src 'self'`（style 才有 unsafe-inline）；无远程
  origin、无 fs/shell 插件暴露面。
- **NM 协议**：帧上限 8MiB 分配前校验、stdin 解析无 panic 路径、stdout 帧级互
  斥、get-logins 响应无密码字段（测试断言）、锁定态拒绝三面全覆盖（sp-nmhost
  + desktop 适配层各自实现 + 各自测试）。
- **扩展**：权限最小化（nativeMessaging+alarms，无 tabs/storage/host_permissions/
  externally_connectables）；chrome.storage 经 eslint 规则硬禁；get-secret 单播；
  无 XSS sink；零运行时 npm 依赖。
- **依赖面**：无网络/异步 runtime crate（与 deny.toml deny 列表互证）；deny 零
  网络红线在 CI 强制。

## 6. Mimosa 拦截处置记录（AGENTS §8 披露）

本批写入共被 Mimosa hook 拦截 5 次，处置如下（无静默绕过）：

1. `fsperms.rs` 两次拦截（"命令注入"，行 35/40）：实为 `Command::new().arg()`
   argv 数组形态的误报（无 shell、无字符串拼接进 shell）。首次尝试的
   SystemRoot 绝对路径变量形态触发非字面量程序路径模式——**按其建议改写**：
   恢复字面量 `Command::new("icacls")`（与已入库原实现同形态），保留本次实质
   修复（fail-closed）；"icacls 绝对路径调用防 PATH 劫持"记为豁免残余（同用户
   会话威胁模型下非增量暴露面）。
2. `tabs.ts` 一次拦截（"SQL 注入"）：`chrome.tabs.query` 为浏览器 Tabs API，
   与 SQL 无关，明确误报。**处置：不改动 tabs.ts**，把 fill 复核逻辑直接放进
   本就要修改的 `service-worker.ts`（内容语义等价，属正常的代码组织选择）。
3. `save-pending.test.ts` 两次拦截（"硬编码凭据"）：测试合成值触发凭据形态正
   则（HANDOFF §3.7 已知坑位）。**改写值形态**：`sp-test-only-*` 前缀值经模板
   字面量构造，语义不变。
