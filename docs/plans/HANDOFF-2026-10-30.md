## 3. 坑位清单（新会话高频踩雷点，务必先读）

1. **NSIS `ReadRegStr` 1024 上限**：超长注册表值返回**空串**——任何"读-改-写"注册表的 NSIS 逻辑都会整值覆盖。PATH 修改一律走 `scripts/add-path.ps1`（.NET RegistryKey，无上限、保类型、防覆盖守卫）。事件全记录见 incident 文档。
2. **PowerShell 脚本编码**：含中文的 .ps1/.nsi 必须 **UTF-8 with BOM**（PS 5.1 与 makensis 否则按 ANSI 误解）；仓库 .gitattributes 强制 LF——**BOM+LF** 即可，写 CRLF 会被 git 拒收。
3. **Git Bash 调原生 exe**：`/D=xxx` 类参数被 MSYS 路径转换吞掉 → 前缀 `MSYS_NO_PATHCONV=1`；但该模式下 `//S` 不再转换，需改回单斜杠 `/S`。
4. **PowerShell 拆参**：未加引号的含点参数（`-DVER=v0.3.0`）会被按点拆开——全部加引号。
5. **NSIS `File` 的 staging 顺序**：.nsi 从 `dist/` 取文件——先完成全部 staging（含 docs/manual），再调 makensis。
6. **GITHUB_TOKEN 默认无 release 写权限**：需要 `permissions: contents: write`（windows job 已配）。
7. **Mimosa 拦截处置**：.rs/.py 测试驱动文件里 `Command::new(...).args([...变量...])` 形态会被误报"命令注入"——改写为字面量数组/合规形态，仍被拦则**内容交用户手动落盘并披露**（不静默绕过）。本轮累计 3 次误报。
8. **分支纪律**：一切变更走 `feature/*|fix/*|docs/*` → PR → CI 七 job 全绿 → 合并；**禁止直推 develop/main**（本会话发生两次，均已推送前矫正，教训已写入 AGENTS.md 草案）。
9. **cargo install 二进制缓存**：rust-cache 含 `~/.cargo/bin` 但 key 含 Cargo.lock 哈希——tauri-cli/cargo-ndk 随锁文件变更频繁失效重编（S0 缓存优化解决）。
10. **android-e2e 抖动**：模拟器 SDK 下载偶发损坏（SeekableByteChannel 错误）→ 直接重跑 failed job 即可，非代码问题。choco 源偶发 504 同理。
