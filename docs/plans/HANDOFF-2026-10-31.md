## 3. 坑位清单（新会话高频踩雷点，务必先读）

1. **NSIS `ReadRegStr` 1024 上限 / PowerShell 含中文需 UTF-8 BOM / MSYS_NO_PATHCONV / PowerShell 拆参 / NSIS staging 顺序 / GITHUB_TOKEN release 权限**——同 2026-10-30 版 §3.1–3.6，不重复。
2. **tauri beforeBuildCommand 的 cwd = src-tauri 父目录**（`desktop`），故写 `pnpm --dir ui build`（不是 `../ui`）。
3. **pnpm 11 拦 esbuild 构建脚本**：desktop/ui 用 `pnpm-workspace.yaml` 的 `allowBuilds: esbuild: true`（对齐 extension）。
4. **keepass-ng additional_attributes 是 HashMap**：custom_fields/tags 读回顺序跨平台不确定——测试断言按名查找/集合比较，禁索引断言（linux CI 实测与 Windows 相反）。
5. **protected 自定义字段不持久化**（DR-005 v0.1 限制）：读回恒 false；GUI/UI 均如实披露。
6. **UniFFI 面变更两步走**：① 重生 Kotlin 绑定入库（Windows 生成与 linux drift check 逐字节一致，含空行）；② **Android app 侧全部构造点适配**（drift check 只管绑定一致，app 编译错误由 android-e2e 的 gradle 编译暴露——FfiEntryDraft 加字段时 SaveConfirmActivity/TestActivity 各需补参）。
7. **Mimosa 拦截面扩大**：`cp`/`sed -i`/`ln` 等经 Bash 落盘源码均拦（用 Write/Edit）；`git add <目录>`（含 .rs）拦（用显式文件路径 add）；测试 fixture 的凭据形态字面量可能误报（改写值形态或移出候选）。
8. **sp run 语义**：打码面 = env 文件**全部值**（含明文，保守设计）；`sp://` 格式校验前置（不提示主密码退 4）、条目存在性解锁后退 3——两类错误时机不同，文档已区分。
9. **CI 分区触发（DR-015）**：`.github/workflows/ci.yml`、根 `Cargo.toml/lock`、`crates/**` 变更 → 全量；纯文档 → 仅 changes job（约 5s）；tag 推送无条件全量；skipped 视为通过。
10. **分支纪律**：一切变更走 `feature/*|fix/*|docs/*` → PR → CI 全绿 → 合并；**验收测试前必须重建**（PATH 里的 sp.exe 与已装桌面版是旧版）。
11. **sp.exe 同名撞车**：win-pyvideotrans v4.17 的 GUI 应用同名——CLI 手册 §1 有三步核对法；测试统一 `& $SP` 全路径。
