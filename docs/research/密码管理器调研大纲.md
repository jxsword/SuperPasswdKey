# 密码/密钥管理软件调研大纲

> 落盘时间：2026-10-25。本大纲为最终版（计划获批 + 复审修正已并入）。

## 1. 背景与目标

以 1Password 收费全功能为基准，调研密码/密钥管理软件（开源免费 + 收费），产出：
(a) 可落地选型结论；(b) SuperPasswdKey 自研需求基线。

核心功能要求 F1–F10：
- F1 自动保存/自动填充
- F2 加解密全程本地运行
- F3 云端只存密文
- F4 密钥文件存本地、主密码不上云
- F5 跨平台（Win/Linux/Android 必选，macOS/iOS 备选）
- F6 私有部署（重点关注）
- F7 CLI 支持（重点关注）
- F8 CLI 临时环境变量注入（进程/shell 结束即失效、不落盘）（最关注）
- F9 批量自动化导入/迁移（散落密钥文件、启动脚本、环境变量 → 扫描识别批量导入、去重分类）
- F10 批量导出（全量条目+附件，支持加密归档与可选明文解密导出）

威胁模型：① 厂商投毒/后门（版本敏感）；② 云同步通道不可信；③ 量子计算远期威胁（KDF/PQC 余量）；④ 明文导出高危操作的安全控制。

## 2. 调研对象清单（四组，约 20 项）

**A 商业 SaaS 对照组**：1Password（基准）、Proton Pass、Dashlane、LastPass（反面教材）、Enpass
**B 开源自部署·个人向**：Bitwarden（官方）、Vaultwarden、KeePass 生态（KeePass 2.x / KeePassXC / KeePassDX / Strongbox / KeePassium）、pass+gopass、Buttercup（活跃度不达标则注明剔除）
**C CLI/机密管理向**：Infisical、HashiCorp Vault（BSL 许可）、OpenBao、SOPS+age（配 direnv/dotenvx 对照）
**D 云盘/同步载体专题**：坚果云、iCloud 中国区、OneDrive/Google Drive/Dropbox、Syncthing、rclone（crypt）、阿里云盘/百度网盘（预计剔除则注明理由）

复审修正补入：
- T4 增加 dotenvx（对比 direnv 的临时注入机制）
- T2/T4 边界：Bitwarden Secrets Manager（自部署能力）与 Infisical 定位区分
- T5 增加实测项：rclone crypt + 坚果云 WebDAV 兼容性与限速
- 1Password `op run` 语义作为 F8 的参考规范单独成节

## 3. 调研维度（D1–D11）

- D1 链接三件套（官网/官方文档/源码，全部实测可达并记核实日期）
- D2 收费模式（免费范围、订阅价、买断、自部署成本）
- D3 加密与密钥架构（本地加解密、KDF 参数、AEAD、零知识、PQC 余量）
- D4 功能对照（以 1Password 全功能为基准表）
- D5 跨平台矩阵（Win/macOS/Linux/Android/iOS/浏览器）
- D6 私有部署（方案、资源、维护成本、暴露面）
- D7 CLI 能力（含 F8 临时注入机制细节）
- D8 安全性核实（审计、CVE 时间线、投毒/事件史、最新版本号、checksum/签名校验）
- D9 特色/专有功能
- D10 云盘同步适配性（WebDAV、冲突合并、并发写风险）
- D11 导入/导出与迁移（批量导入来源格式与 CLI 接口、从环境变量/脚本/密钥文件扫描导入、全量导出+附件、明文解密导出选项及安全控制、两两迁移闭环、辅助秘密扫描工具链 gitleaks/trufflehog/detect-secrets）

## 4. 安全核实专项

渠道：官方安全公告/白皮书 + GitHub Security Advisories/issues + 第三方社区（Reddit/HN/安全媒体/审计机构）。
重点事件（逐一验证，不凭记忆）：LastPass 2021–2022 事件链；KeePass 内存泄露 CVE 与假冒站点分发；Bitwarden iframe 填充 CVE；1Password Okta 相关事件；npm/PyPI 供应链投毒波及；Vaultwarden 非官方维护风险。
版本敏感性：结论标注"截至 2026-10-25 最新版本"；投毒注明受影响版本；给出官方 checksum/签名校验方法。
明文导出风险：触发条件与残留风险（临时文件、shell history、剪贴板）。

## 5. 云盘同步专题要点

安全前提（端到端加密下云盘仅密文管道）、跨平台一致性（WebDAV 直连 vs 本地同步客户端）、冲突处理（KeePass 三向合并 vs 单文件覆盖）、云账号安全（2FA/版本历史/回收站）、与自建服务器成本安全对比。
